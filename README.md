# 주식·투자 상식 사전 — 계좌 개설부터 ETF·연금까지

주식이 처음인 분들을 위한 투자 상식 사전이에요. 증권계좌를 아직 안 만들어본 완전 초보부터, 매매는 해봤지만 개념 정리가 안 된 입문자까지를 대상으로 해요. 각 챕터는 검색으로 궁금할 만한 질문 하나에 완결로 답하는 독립적인 글이라서, 처음부터 순서대로 읽어도 되고 지금 궁금한 챕터만 골라 봐도 괜찮아요.

읽는 순서를 추천하자면 파트 1부터 6까지 차례로 읽는 걸 권해요. 뒤 챕터는 앞 챕터 지식을 살짝 전제로 하는 경우가 있는데, 그럴 땐 본문에 한두 줄 요약과 함께 관련 챕터 링크를 달아둘 거예요. 그래서 순서를 안 지키고 봐도 흐름을 놓치지 않아요.

파트 7(투자 트렌드)은 다른 파트와 성격이 달라요. 미리 다 써놓는 챕터 목록이 아니라, 그때그때 유행하는 투자 방식이나 이슈가 생길 때마다 계속 새 글이 추가되는 수시 업데이트 파트예요. 지금은 7-1 하나만 계획되어 있고, 앞으로 계속 늘어날 예정이에요.

## 집필 순서

파트 1 → 2 → 3 → 4 → 5 → 6 순서로 순차 집필해요. 초보 유입 검색량이 많고 뒤 챕터의 내부 링크 기반이 되는 파트부터 채우는 거예요. 파트 7은 위 순서와 무관하게 수시로 챕터가 추가돼요.

## 집필 규칙 요약

- 각 챕터는 하나의 검색 질문에 완결로 답해요 (제목도 검색 질문형으로 지어요).
- 앞 챕터 지식이 필요하면 한두 줄 요약 + 내부 링크로 처리해요.
- 초보 눈높이의 구체적 예시를 챕터당 최소 1개 넣어요.
- 파트 7 글에는 반드시 작성일을 명시하고, 낡아도 삭제하지 않고 아카이브로 유지해요.
- 트렌드 콘텐츠는 집필 시 웹 리서치를 병행해요 (지식 컷오프 이후 정보 반영).
