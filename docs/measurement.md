## 분석 도구 결정 사항

분석 도구는 지금 설치하지 않았어요. 필요해지면 하나만 고르세요.

| 선택지 | 장점 | 단점 |
|---|---|---|
| Cloudflare Web Analytics (권장) | 이미 Cloudflare Pages를 쓰고 있어 추가 계정이 필요 없고, 쿠키 없이 페이지뷰 측정 가능 | 검색어와 전환 분석은 없음 |
| Google Analytics 4 | 유입 경로와 행동을 자세히 분석 | 쿠키 사용, 동의·개인정보 고지 범위 증가 |

어느 쪽이든 설치한 날 `about/privacy.md`의 「방문 통계와 브라우저 저장」 절과 시행일을 함께 고쳐야 해요.

## 콘텐츠 개선 판단 기준

| 관측 | 먼저 확인할 것 | 조치 |
|---|---|---|
| 노출이 많고 CTR이 낮음 | 검색어와 제목·설명의 의도가 맞는지 | 제목·설명 수정. 글의 답이 맞지 않으면 본문부터 수정 |
| 관련 검색어가 있지만 답변이 부족함 | 그 질문에 답하는 문장이 본문에 있는지 | 본문 보강 |
| 같은 검색어에 여러 글이 겹침 | 글마다 답하는 질문이 다른지 | 역할 정리, 내부 링크 정리, 필요하면 통합 |
| 색인되지 않음 | URL 검사, canonical, robots, 응답 코드 | 기술 문제와 콘텐츠 품질 문제를 구분해 조사 |

FAQ나 구조화 데이터를 추가해도 검색 노출이 보장되지는 않아요. 측정 결과와 독자 필요가 맞을 때만 작업하세요.
