# 파트 4 (ETF·펀드·연금으로 하는 투자) 집필 구현 계획

> **For agentic workers:** 이 계획은 컨트롤러가 직접 집필하고 **최종 전수 리뷰 한 번**으로 검증한다(사용자 결정). 태스크별 리뷰는 두지 않는다. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 파트 4 「ETF·펀드·연금으로 하는 투자」 6개 챕터를 집필하고, 파트 3이 파트 4로 넘긴 빚 5건을 갚는다.

**Architecture:** 파트 1~3과 동일한 하이브리드 구조 — 각 챕터는 검색 질문 하나에 완결로 답하는 독립 글이면서, 순서대로 읽으면 책이 된다. 파트 4의 축은 **"개별 종목 고르기"에서 "바구니와 그릇 고르기"로의 전환**이다. 4-1~4-3은 무엇을 담을지(ETF), 4-4~4-6은 어디에 담을지(절세 계좌)를 다룬다.

**Tech Stack:** Markdown, mermaid, VitePress(빌드·검증), Node 22, `node --test`, git.

**브랜치:** `main`에서 `feat/part4`를 따서 작업하고, 완료 후 `main`에 머지·푸시한다.

## Global Constraints

파트 1~3에서 확립된 규칙. **모든 태스크에 적용된다.**

1. 각 챕터는 하나의 검색 질문에 완결로 답한다. 검색으로 도착한 독자가 다른 글을 안 읽어도 만족해야 한다.
2. 앞 챕터 지식이 필요하면 **한두 줄 요약 + 내부 링크를 한 문장 안에** 넣는다. 요약 없는 회상은 금지.
3. 초보 눈높이의 구체적 예시를 챕터당 최소 1개, 실제 숫자를 넣어 포함한다. **산술은 처음부터 끝까지 한 번에 재계산해 검산한다**(파트 3에서 단계별로만 검산하다 3-1 실수령액이 어긋났다).
4. 시의성 있는 사실에는 "2026년 8월 기준" as-of 표기를 붙인다. 개념 정의에는 붙이지 않는다.
5. 파일명은 README·`.vitepress/lib/chapters.js`의 슬러그와 정확히 일치해야 한다.
6. 시각화를 적극 사용한다. **mermaid 라벨에는 괄호·따옴표·슬래시·화살표를 넣지 않는다.**
7. 대상 독자는 완전 초보~입문자. **모든 용어를 각 챕터에서 첫 등장 시 설명한다.**
8. 중급 이상 심화 금지. 파생상품, 레버리지·인버스 상품의 상세 메커니즘, 기술적 분석은 범위 밖이다.
9. **금융회사 실명을 쓰거나 순위를 매기지 않는다.** 거래소·협회·정부기관은 실명 사용 가능(한국거래소, 금융위원회, 금융감독원, 국세청, 예탁결제원).
10. 실존 상품·기업에 지어낸 수치를 붙이지 않는다. 가상 상품·기업을 쓴다.
11. 톤은 해요체. 파트 1~3 열아홉 챕터와 동일한 목소리.
12. 마크다운 위생: `)**한글` 패턴 금지. 커밋 전 검사.
13. **frontmatter의 `part`·`order`는 필수이며 숫자여야 한다.** 빠지면 빌드가 조용히 통과하면서 SEO가 통째로 꺼진다.
14. **미집필 챕터 링크는 상대경로 + `.md`로 끝나야 한다.** 어기면 빌드가 dead link 오류로 죽는다.
15. `##` 섹션이 4개 이상이면 3번째 섹션 앞에 광고가 삽입된다.
16. `keywords`는 검색 색인에, `description`은 검색 결과·SNS 미리보기에 그대로 노출된다.

## 파트 4 전용 제약 (새로 추가)

파트 4는 **세법과 계좌 제도가 본진**이라 파트 3보다 오류 비용이 크다. 아래 7개는 모든 태스크에 적용된다.

1. **운용사·상품 실명을 쓰지 않는다.** ETF는 상품명에 운용사 브랜드(KODEX·TIGER·ACE 등)가 붙어 있지만, **브랜드명도 개별 상품명도 쓰지 않는다.** "같은 S&P500을 담는 ETF가 여러 운용사에서 나와요" 수준으로 구조만 설명하고, 계산 예시는 **가상 상품**(A운용사 S&P500 ETF, B운용사 S&P500 ETF)으로 쓴다. 상품이 상장폐지되거나 보수가 바뀌어도 글이 낡지 않는 이점이 있다.

2. **발표된 제도와 시행 중인 제도를 반드시 구분한다. 파트 4의 최대 함정이다.**
   2026년 8월 3일 발표된 「2026년 세제개편안」에 **생산적금융 ISA** 신설이 들어 있다(국내 상장주식·국내 주식형 펀드 대상, 이자·배당 전액 비과세, 연 2,000만원·총 2억원, 청년 납입액 10% 소득공제). **하지만 이건 발표 단계이고 국회 통과 전이며, 시행 예정일은 2027년 1월 1일 이후 신규 가입분이다.** 일반 ISA에도 변경이 예고돼 있다.
   **시행 중인 것처럼 쓰면 독자가 지금 가입할 수 있다고 오해한다.** 1-4가 KRX 애프터마켓을, 3-2가 나스닥 23시간 체제를 처리한 것과 **같은 수위로** 헤지한다 — 현행 제도를 본문으로 쓰고, 예고된 변경은 별도 절에서 "아직 시행 전이라 지금은 위 내용대로예요"로 닫는다.

3. **한도·공제율은 소득 구간에 따라 달라진다. "누구나 얼마"라고 쓰면 틀린다.** 연금계좌 세액공제율은 총급여 5,500만원(종합소득금액 4,500만원)을 경계로 15%와 12%로 갈리고, ISA 비과세 한도도 일반형과 서민형이 다르다. **반드시 구간을 밝혀서 쓴다.**

4. **혜택만 쓰고 제약을 빼면 위험한 글이 된다.** 절세 계좌의 본질은 "세금을 깎아주는 대신 돈이 묶인다"이다. 연금계좌는 만 55세 이전 인출 시 혜택을 토해내고, ISA는 의무가입기간이 있다. **각 계좌를 소개할 때 혜택과 제약을 같은 무게로 쓴다.** [1-2](../part1-basics/1-2-open-brokerage-account.md)가 이미 "정해진 나이나 기간 전에 돈을 빼면 혜택을 토해내야 해서, 투자에 익숙해진 뒤 만들어도 늦지 않아요"라고 써뒀으니 그 톤을 이어받는다.

5. **4-6은 조건별 분기로 쓰고 단일 정답을 주지 않는다.**(사용자 결정) "이런 상황이면 이 순서"를 연소득·인출 시기·다른 금융소득 기준으로 갈라서 제시한다. "보통 이 순서를 권해요"처럼 하나를 밀지 않는다. 다만 **분기를 실제로 제공해야 한다** — 3-3이 이 챕터로 판단을 넘겨뒀으므로, 비교표만 늘어놓고 "각자 판단하세요"로 끝내면 독자가 링크를 따라와 빈손으로 돌아간다.

6. **수익률·보수율·금액은 전부 가정형으로 쓴다.** 파트 3의 환율·지수 규칙을 파트 4의 수익률·보수율로 확장한 것이다. "연 7% 수익을 가정하면" 식으로 쓰고, 특정 상품의 실제 수익률을 현재값처럼 제시하지 않는다.

7. **레버리지·인버스 상품은 "이런 것도 있다"는 한 문단 경고까지만.** 초보 대상 콘텐츠에서 상세 메커니즘을 다루면 권유로 읽힐 위험이 크다. 4-3에서 한 문단으로 위험만 짚고 넘어간다.

## 파트 1~3에서 확정된 용어 정의 (충돌 금지)

**다르게 정의하면 안 된다.** 파트 1에서 이 유형의 충돌이 세 번 발생했다.

### 파트 1~2 확정분 (파트 3 계획서에서 승계)

| 용어 | 확정된 정의 | 정의된 곳 |
|---|---|---|
| 주가 | 회사 가치 ÷ 주식 수가 아니다. 기대가 얹혀 사겠다는 사람과 팔겠다는 사람 사이에서 정해지는 가격 | 1-1 |
| 발행시장 vs 유통시장 | 회사 통장에 돈이 들어가는 건 새로 발행해 팔 때뿐 | 1-1 |
| 배당 | 그해 이익이 아니라 **그동안 쌓아온 이익 가운데 일부** | 1-1 |
| 단일가매매 / 동시호가 | 동시호가는 단일가매매의 **부분집합** | 1-3, 1-4 |
| 시가총액 | 주가 × 발행주식수. 시장이 지금 이 순간 매긴 값 | 1-6 |
| 양도소득세 | 주식을 팔아 생긴 이익에 매기는 세금. 국내 상장주식은 소액주주에게 사실상 없다 | 1-5 |
| 원천징수 | 지급하는 쪽이 세금을 미리 떼고 나머지만 주는 방식 | 1-5 |
| **금융소득종합과세** | **이자·배당을 합쳐 연 2천만원을 넘으면 다른 소득과 합산해 세금을 더 내는 제도** | 1-5 |
| 절세계좌 3종 | 연금저축펀드 / IRP / ISA. 정해진 나이·기간 전에 빼면 혜택을 토해낸다 | 1-2 |
| 지수 | **기준시점 대비 주가 흐름의 배율**. "지수 2,500 = 시총 25배"는 틀린 서술 | 2-2 |
| 시가총액 가중 | 시가총액이 큰 종목일수록 지수 영향력이 커지는 방식 | 2-2 |
| 배당수익률 | 배당금 ÷ 주가. **주가가 떨어져도 수익률은 올라가는 함정** | 2-3 |

### 파트 3 확정분 (파트 4에서 반드시 상속)

| 용어 | 확정된 정의 | 정의된 곳 |
|---|---|---|
| 해외주식 양도소득세 | **22%**(양도소득세 20% + 지방소득세 2%), 연 **250만원** 기본공제 | 3-1, 3-3 |
| 기본공제 250만원 | **종목별이 아니라 1년에 한 번. 국내·국외주식 합산 1회** | 3-3 |
| 손익통산 (해외주식) | 같은 해 해외주식끼리 가능. **비과세인 국내 상장주식과는 불가** | 3-3 |
| 양도차익 | 양도가액 − 취득가액 − 필요경비(수수료). **수수료까지 뺀 뒤의 순수 이익** | 3-1, 3-3 |
| 분류과세 vs 종합과세 | 해외주식 **양도소득은 분류과세**라 종합과세와 무관. **배당은 금융소득이라 종합과세 대상** | 3-3 |
| 국내상장 해외 ETF 과세 | 매매차익도 **배당소득세 15.4%**, 250만원 공제 없음, 종합과세 대상 | 3-3 |
| 환헤지(H) / 환노출(UH) | 헤지는 환율 영향을 지우는 대신 **비용이 든다**(양국 금리차에서 나옴) | 3-4 |
| 가격 가중 vs 시총 가중 | 다우만 가격 가중. S&P500·나스닥·코스피는 시총 가중 | 3-5 |
| 나스닥종합 vs 나스닥100 | 종합은 나스닥 상장 주식을 사실상 전부, 100은 금융업 뺀 상위 100개. **ETF 상당수는 나스닥100 추종** | 3-5 |

**파트 4에서 부딪히기 쉬운 지점 4곳:**

- **4-3의 분배금** — 1-1의 배당 정의와 2-3의 배당수익률 함정을 그대로 상속해야 한다. ETF 분배금도 "높으면 좋다"가 아니다.
- **4-5의 ISA 손익통산** — 3-3이 확정한 "해외주식은 비과세 국내주식과 통산 불가"와 **다른 이야기**다. ISA는 계좌 안에서 상품 간 통산이 되는 것이므로, 3-3을 부정하지 말고 **"계좌 밖에서는 안 되던 게 ISA 안에서는 된다"**로 대비시킨다. 이게 ISA의 핵심 장점이다.
- **4-5·4-6의 금융소득종합과세** — 1-5가 정의하고 3-3이 상속한 "이자·배당 합쳐 연 2천만원 초과" 기준을 그대로 쓴다.
- **4-6의 해외주식 직투 vs 국내상장 해외 ETF** — 3-3이 표까지 만들어 넘긴 판단이다. **값을 바꾸지 말고 이어받아 계좌 변수를 더해 완성한다.**

### 확인 못 한 값 (집필 시 반드시 1차 출처 확인)

- 연금 수령 시 **연금소득세율**(나이별 차등 여부와 구체 세율)
- 연금계좌 **중도해지 시 기타소득세율**
- **IRP의 위험자산 투자 한도**(주식형 상품에 얼마까지 담을 수 있는지)
- ISA **만기 자금을 연금계좌로 옮길 때의 추가 세액공제**(전환금액의 10%, 한도)
- ISA **서민형 가입 자격 요건**(총급여·종합소득 기준선)
- 연금저축과 IRP의 **중도인출 가능 사유** 차이
- **일반 ISA에 예고된 변경**(2026 세제개편안에 "5년 제한" 관련 언급이 있었음 — 정확한 내용 확인 필요)
- ETF **총보수와 실부담비용(TER)** 의 관계, 기타비용·매매중개수수료 포함 여부

- `## 펀드와 무엇이 다른가`: **비교표 필수** — 매매 방법 / 가격이 정해지는 시점 / 매매 비용 / 최소 투자금액 / 실시간 확인. 일반 펀드는 하루 한 번 정해지는 기준가로 사고팔지만 ETF는 [1-3](../part1-basics/1-3-how-to-buy-stocks.md)의 호가창에서 실시간으로 거래된다
- `## ETF는 어떻게 만들어지나`: **mermaid 필수** — 지수 선정 → 운용사가 그 지수대로 종목 바구니 구성 → 거래소 상장 → 투자자가 매매. 유동성공급자가 호가를 대주는 역할까지 한 문단. 라벨에 괄호·따옴표·슬래시·화살표 금지

- `## 분배금`: 바구니 안 종목들이 준 배당이 모여 투자자에게 나오는 것. [1-1](../part1-basics/1-1-what-is-stock.md)의 배당 정의를 한 줄 요약 + 링크
