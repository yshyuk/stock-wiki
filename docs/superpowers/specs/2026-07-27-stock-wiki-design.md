# stock-wiki 설계 문서

- 작성일: 2026-07-27
- 상태: 사용자 승인 완료 (목차·구조 확정)

## 1. 개요

주식·투자 상식을 다루는 온라인 책 형태의 문서 프로젝트.
위키독스(예: https://wikidocs.net/book/2970)의 "목차 트리 + 챕터별 본문" 스타일을 따르되,
게시는 위키독스가 아닌 **개인 사이트**(추후 구축)에 한다.

## 2. 목적과 수익 모델

- 주 목적: **광고 수익화** (애드센스 등 트래픽 기반 수익)
- 따라서 검색(SEO) 유입이 핵심 → 챕터 구조가 검색어 단위에 대응해야 함
- 위키독스는 애드센스를 붙일 수 없으므로 개인 사이트로 결정

## 3. 대상 독자

- 완전 초보: 증권계좌도 없는 사람 (계좌 개설·주문부터 다룸)
- 입문자: 매매는 해봤지만 개념 정리가 안 된 사람 (PER/PBR, 시장 구조 등)
- 중급 이상 심화 콘텐츠는 범위 밖

## 4. 구조: 하이브리드 (C안, 확정)

- 책의 파트/챕터 구조를 유지하되, **각 챕터는 하나의 검색 질문에 완결로 답하는 독립 글**
- 순서대로 읽으면 학습서, 검색으로 들어오면 단일 글로도 완결
- 고려했던 대안:
  - A안(순수 학습서 구조): SEO 유입에 불리하여 제외
  - B안(순수 위키형): 책의 정체성이 사라져 제외
- C안 선택 이유: 광고 수익(검색 유입)과 위키독스식 책 형태를 동시에 만족.
  기간마다 유행하는 투자방식을 트렌드 파트에 독립 글로 계속 추가하기에도 적합.

## 5. 확정 목차

책 제목(가제): **주식·투자 상식 사전 — 계좌 개설부터 ETF·연금까지**

### 파트 1. 주식 투자, 처음이라면 (완전 초보)
- 1-1. 주식이란 무엇인가 — 회사 지분을 산다는 것의 의미
- 1-2. 증권계좌 개설, 어디서 어떻게 하나
- 1-3. 주식 사는 법 — 호가창, 시장가/지정가 주문 이해하기
- 1-4. 매매 시간과 장전·장후 거래
- 1-5. 수수료와 세금, 주식 사고팔면 뭘 떼일까
- 1-6. 시가총액·주가·거래량, 숫자 읽는 법

### 파트 2. 국내 주식시장 이해하기
- 2-1. 코스피 vs 코스닥, 뭐가 다른가
- 2-2. 코스피 지수는 어떻게 계산되나
- 2-3. 배당이란 — 배당락, 배당 기준일, 배당수익률
- 2-4. 공모주 청약, 어떻게 참여하나
- 2-5. 유상증자·무상증자·액면분할이 주가에 미치는 영향
- 2-6. 상한가·하한가·서킷브레이커 — 시장의 안전장치
- 2-7. 공매도란 무엇이고 왜 논란인가

### 파트 3. 미국주식·해외투자
- 3-1. 미국주식, 왜 하는가 — 국내주식과의 차이
- 3-2. 미국주식 거래 시간과 프리마켓·애프터마켓
- 3-3. 미국주식 세금 — 양도소득세 250만원 공제 이해하기
- 3-4. 환율과 환전 — 환헤지 vs 환노출
- 3-5. S&P500·나스닥·다우 — 3대 지수 구분하기
- 3-6. 미국 배당주와 배당 성장 투자

### 파트 4. ETF·펀드·연금으로 하는 투자
- 4-1. ETF란 무엇인가 — 펀드와 뭐가 다른가
- 4-2. 인덱스 투자 — 왜 "시장을 사라"고 하는가
- 4-3. ETF 고르는 법 — 운용보수, 괴리율, 추적오차
- 4-4. 연금저축펀드 vs IRP — 세액공제 활용법
- 4-5. ISA 계좌, 왜 만능통장이라 부르나
- 4-6. 절세 계좌 3종 우선순위 — 뭐부터 채워야 하나

### 파트 5. 기업분석·재무제표 입문
- 5-1. 재무제표, 어디서 보고 뭘 봐야 하나 (DART 사용법)
- 5-2. PER — 이 주식은 비싼가 싼가
- 5-3. PBR과 ROE — 자산과 수익성으로 보는 기업
- 5-4. 매출·영업이익·순이익, 손익계산서 읽기
- 5-5. 부채비율과 유동비율 — 망하지 않을 회사 고르기
- 5-6. 가치평가의 한계 — 지표만 보면 안 되는 이유

### 파트 6. 알아두면 돈이 되는 투자 상식
- 6-1. 금리와 주가의 관계 — 왜 금리가 오르면 주가가 떨어지나
- 6-2. 인플레이션과 투자 — 현금은 왜 녹는가
- 6-3. 분산투자와 포트폴리오 — 계란을 나눠 담는 법

- 6-5. 복리의 힘 — 장기투자가 유리한 수학적 이유
- 6-6. 경제 뉴스 읽는 법 — FOMC, CPI, 고용지표가 뭐길래
- 6-7. 흔한 투자 사기 유형과 피하는 법

## 6. 집필 규칙

1. 각 챕터는 하나의 검색 질문에 완결로 답한다 (제목도 검색 질문형).
2. 앞 챕터 지식이 필요하면 한두 줄 요약 + 내부 링크로 처리한다.
3. 초보 눈높이의 구체적 예시를 챕터당 최소 1개 포함한다.
4. 트렌드 파트(파트 7) 글에는 반드시 작성일을 명시한다. 낡아도 삭제하지 않고 아카이브로 유지한다.
5. 트렌드 콘텐츠 집필 시에는 웹 리서치를 병행한다 (지식 컷오프 이후 정보 반영).
6. 파일 형식은 마크다운 — 추후 어떤 사이트 틀(정적 사이트 생성기 등)에도 그대로 사용 가능해야 한다.
7. 개념 설명에 도움이 되면 도형·시각화 자료(다이어그램, 표, 그래프)를 적극 넣는다.
   다이어그램은 mermaid(마크다운 내장) 우선, 복잡한 그림은 이미지 파일로 파트 폴더 하위 `images/`에 저장한다.

## 8. 사이트 요구사항 (추후 구축 시 반영)

사이트 구축은 별도 프로젝트이지만, 사이트 틀 선택에 영향을 주는 요구사항을 미리 기록한다.

1. **단어 검색**: 사이트 내 검색창에서 단어를 검색하면 검색 결과 페이지가 나오고,
   결과를 클릭하면 해당 챕터 페이지로 이동한다.
   → 정적 사이트에서도 Pagefind, lunr.js 등으로 구현 가능. 사이트 생성기 선택 시 검색 지원 여부를 필수 기준으로 삼는다.
2. **mermaid 다이어그램 렌더링 지원**: 집필 규칙 7의 시각화 자료가 사이트에서 그대로 렌더링되어야 한다.
3. 위키독스 스타일의 목차 트리 내비게이션 (기존 설계 전제 재확인).

## 9. 범위 밖 (이번 단계에서 하지 않는 것)
