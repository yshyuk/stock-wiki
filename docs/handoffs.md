# 파트 3 착수 전 인수인계 (파트 2 종료 시점)

파트 1(1-1~1-6)·파트 2(2-1~2-7) 집필 과정에서 나온 정보 중 `.superpowers/` 작업 로그에만 남아 있고 머지 후 사라지는 내용을 정리한 문서예요. 파트 3 이후 챕터를 쓰기 전에 이 문서를 먼저 확인하세요.

## 1. 미해결 — 동시호가 배분 우선순위 (1-3·1-4·2-6 모두 헤지 유지 중)

동시호가(상·하한가 단일가매매) 상황에서 물량을 나누는 내부 순서 — 위탁매매우선이 수량우선에 앞서는지 — 를 1차 출처로 확정하지 못했어요.

- 유가증권시장 업무규정 시행세칙 제34조 원문을 여러 차례 확보 시도했으나 실패했습니다.
- 법제처 easylaw는 위탁자우선을 ETF·ETN·ELW로 한정해 서술합니다.
- KRX regulation 페이지는 위탁매매우선을 언급하지 않고 "매매수량단위 100배 → 잔량 1/2 → 잔량" 단계별 정량배분만 명시합니다.
- 2차 출처(금투협 등)는 위탁매매우선이 수량우선에 앞서는지를 놓고 서로 갈립니다.

**파트 2 완료 시점 기준으로도 여전히 미해결이에요.** 2-6(상한가·하한가·서킷브레이커)도 내부 순서를 단정하지 않고 1-3·1-4와 같은 수위로 헤지한 채 마무리했습니다("접수 시간의 앞뒤를 따지지 않고 다른 기준으로 물량을 나눠줘요" 정도로만 서술). **1-3·1-4·2-6 세 챕터 모두 이 헤지를 유지하고 있고, 이후 어떤 챕터에서도 이 순서를 단정하지 마세요.** KRX 규정집 PDF나 유료 법령 DB 등 공개 웹 밖 경로로 원문을 먼저 확보하기 전까지는 확정하면 안 됩니다.

## 2. 2026년 9월 14일 — 1-4 시간표의 만료일

1-4(매매 시간)는 KRX 애프터마켓(16:00~20:00)이 **2026년 9월 14일** 시행 예정이고, 프리마켓은 2027년 말로 연기됐다고 서술합니다. 현재는 "아직 시행 전이라 지금 시간표는 위의 표대로예요"라고 명시해 두었어요.

그 날짜가 지나면 1-4의 메인 시간표(정규장 09:00~15:30, 시간외단일가 16:00~18:00 등 KRX 기준 표)가 낡습니다. **파트 1에서 가장 큰 조용한 노후화 리스크**이니, 2026년 9월 14일 이후 파트 1을 다시 열어 KRX 12시간 체제 시행 여부와 실제 운영 시간표를 재확인하고 1-4를 갱신하세요.

  소스를 한 글자도 바꾸지 않고 그대로 옮긴 페이지를 만들어 사이트 소유자가 브라우저에서 직접
  확인했어요. **네 개 모두 그림으로 정상 렌더되고 한글 라벨도 깨지지 않아요.** 1-1의 화살표

  mermaid 코드 블록이 플러그인 마운트 지점으로 정상 치환되고(raw 코드 블록 0건, 마운트 1건씩),

### 집필할 때 알아야 할 것

- **마크다운은 그대로 두면 돼요.** 사이트가 빌드 시점에 변형을 처리해요. 미집필 챕터를 가리키는
  링크를 미리 써 둬도 「집필 예정」 표시로 렌더되고, 그 챕터를 쓰면 자동으로 링크가 살아나요.
- **`##` 섹션이 4개 이상이면 3번째 섹션 앞에 광고가 들어가요.** 섹션 구성을 짤 때 참고하세요.
- **frontmatter의 `keywords`가 검색 색인에 들어가요.** 그동안은 쓰이지 않았는데 이제 실제
  검색어로 동작하니, 독자가 칠 법한 표현을 넣어 주세요.
- **`description`은 검색 결과와 SNS 미리보기에 그대로 노출돼요.** 이미 그렇게 쓰고 있지만,
  앞으로도 문장으로 완결되게 써 주세요.
- **`date`는 구조화 데이터의 `datePublished`가 돼요.**

### 남은 사항

  여부를 다시 판단하세요.
